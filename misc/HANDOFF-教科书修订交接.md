## 3. 核心规范速览（详见 AGENTS.md）

1. **每章统一体例**：章首 meta（本章定位/本章产出/建议读者/前置）→ 本章导学（学习目标/前置知识/章节地图）→ 正文 → 反模式与红线 → 本章小结（+动手自检）→ 练习与思考（基础/进阶/挑战）→ 在线全书（延伸阅读）。
2. **内容归属原则**：课程紧密相关 → 直接写入；不紧密 → 只给链接（`https://www.cloudzun.com/fde-course/` + 章节名，不配锚点）。**禁止"延伸阅读 → FDECore 第 X 章"的依赖式写法**。
3. **无内部解释性表述（红线）**：读者看到的是最终交付物，禁止出现"我们从 X 讲起而不是 Y""这是 1.1 想纠正的""本书刻意设计""认知篇"等内部叙事/旧版本痕迹；正向陈述，读者不知所以的话不写。**禁止 💡 图标**（"一句话记住本章"不带 💡）。
4. **mermaid 布局规则**：元素（节点）>4 一律垂直（`flowchart TB/TD`）；≤4 才允许水平（LR）；**subgraph id 用英文**（中文 id 渲染不稳）；虚线边标签内**不能含 `.`**（会破坏 `-.标签.->` 语法）；避免 subgraph 间连边/自环（用纯节点图最稳）；图下带图题 `*图 N-x：标题*`；配色沿用 `#3949ab/#f5ece0/#e4efe4/#fdecea/#dbe4f0`。
5. **术语统一**（见 AGENTS.md 第 6 节）：FDE、三层含义、三重角色、卖人力→卖能力、四条红线、四阶段、PPT 框架、能力回注、三角色（Echo/Delta/Engineering）、三脚手架、三 SOP、五实操总分总、西岭案例。
6. **编号纪律**：新增小节顺延编号；重编号必须全文 grep `N\.[0-9]` 同步交叉引用。
7. **溯源纪律**：官方引文必须有出处；教材提炼标注"教材提炼"；时效性数据标注时间点。
