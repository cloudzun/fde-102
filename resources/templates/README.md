# resources/templates/ · 随书模板包

> **性质：** 随书资源包中的**模板唯一权威**（`resources/` 目录规范见 AGENTS.md）。
> **用途：** 学员直接套用的可填写模板；教科书与《实验手册》（`labs/`）中出现的同源模板以本目录为准——**修改模板时，同步更新本目录与报告中引用的正文/手册相应位置**。
> **与 labs/ 的关系：** `labs/` 手册仍自包含（讲师离线可用），其内嵌模板与本目录同源；以本目录为模板权威。
