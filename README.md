FDE（前沿部署工程师）能力培养的**实战教科书**仓库。

## 目录结构（公开交付物）

```
FDE实战课程20260830/
├── README.md          # 本文件：仓库总览与目录说明
├── AGENTS.md          # 编写与迭代规范（协作者/代理必读）
├── textbook/          # 教科书正文（唯一工作底稿）
│   ├── 00_导读与体例说明.md
│   ├── 第01章 ~ 第16章.md
│   └── assets/        # 正文引用的图片素材
├── labs/              # 实验手册正式册（实操一~五 + 实操四B + 复盘真实项目）
├── resources/         # 随书资源包（模板、启动提示词向导、工具速查、认证量规等）
└── 站点构建            # mkdocs.yml、assets/、javascripts/、scripts/、.github/（GitHub Pages）
```

> 本仓库对外公开的**教学交付物**：教科书 `textbook/`、实验手册 `labs/`、随书资源包 `resources/`，以及 GitHub Pages 站点构建文件。内部过程资料（课件源码、评审/修订/交接文档、参考资料库）仅存在于本地工作目录，不随本仓库分发。

## 正文不改名纪律

`textbook/` 下章节文件固定 `第NN章_<主题>.md`（两位序号），**文件名一旦确定不要随意改名**，以免破坏全文交叉引用。
