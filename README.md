# 人工智能工程师（高级）FDE 认证培训 · 教科书

FDE 能力培养的**实战训练教科书**仓库。

## 目录结构

```
FDE实战课程20260830/
├── README.md          # 本文件：仓库总览与目录说明
├── AGENTS.md          # 编写与迭代规范（协作者/代理必读）
├── textbook/          # 教科书正文（唯一工作底稿）
│   ├── 00_导读与体例说明.md
│   ├── 第01章 ~ 第15章.md
│   └── assets/        # 正文引用的图片素材
├── resources/         # 随书资源包（模板、启动提示词向导、工具速查等）
├── references/        # 参考资料库（行业/技术/模型/算力调研，只读）
└── misc/              # 中间过程文档（交接、大纲、技术规格——非最终交付物）
```

> `misc/` 只存过程性文档（HANDOFF 交接、编写大纲、技术规格），不属于最终教学交付物；正文改动一律在 `textbook/` 内进行，规范见 `AGENTS.md`。

## 正文不改名纪律

`textbook/` 下章节文件固定 `第NN章_<主题>.md`（两位序号），**文件名一旦确定不要随意改名**，以免破坏全文交叉引用。
