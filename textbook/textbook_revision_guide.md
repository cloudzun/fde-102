## 1. 修订总览与优先级说明

经过对全书 16 个章节的系统审阅，本教材整体质量极高，贯穿案例生动、方法论自洽，且具有极强的工程实操性。当前存在的问题主要集中在：
- **交叉引用与跳章问题**（因版本演进导致的章号未同步）
- **部分图表逻辑漏洞与渲染缺陷**（如决策树死分支、Mermaid 负值截断）
- **部分章节间的内容重叠**（如 Ch3 与 Ch4 的 Echo/Delta 职责、三处能力金字塔图）
- **实操前置约束与边界处理的补充**（如文档解析环境降级、汇报禁用词扩充）

### 优先级划分规则
- 🔴 **P0（硬伤级）：** 语法/逻辑错误、死链接、导致代码/图表报错或误导学员的问题。
- 🟡 **P1（体验级）：** 章节间内容重复、缺乏递进过渡、概念定义混淆等影响阅读体验的问题。
- 🟢 **P2（严谨级）：** 术语不规范、时效性描述缺乏限定、技术背景补充。
- 🔵 **P3（润色级）：** 实操教学的防御性提示、格式微调、排版对齐。

### 2.3 第 02 章 Mermaid xychart 负值截断错误
- **所在文件：** `第02章_为什么需要FDE.md`（第 236 行）
- **原问题：**
  ```mermaid
  xychart-beta
      title "Palantir 2018–2025 盈利趋势"
      x-axis ["2018", "2019", "2020", "2021", "2022", "2023", "2024", "2025"]
      y-axis "百分比" 0 --> 90
      bar [50.0, 54.0, 68.0, 78.0, 78.6, 80.6, 82.0, 82.4]
      line [-97.5, -78.4, -107.0, -34.0, -19.5, 6.8, 17.5, 23.0]
  ```
  *分析：* `y-axis "百分比" 0 --> 90` 导致负值数据（-19.5% 至 -107%）无法正常显示或渲染异常。
- **修改建议：**
  将 y-axis 下限调整为负数区间，或将毛利率与净利率拆分为两张图，或修改为：
  ```markdown
      y-axis "百分比" -30 --> 90
  ```
  并在图表下方增加说明：*“注：2018-2020 年极端亏损点在图中做截断展示，重点观察 2021 年起净利率转正爬升趋势。”*

### 2.4 第 05 章 选型决策树 q3 逻辑漏洞
- **所在文件：** `第05章_Echo工作法_Discovery.md`（图 5-7，第 286~296 行）
- **原问题：**
  决策树中第三个判断节点：
  `q3{需要自主决策 + 调工具 + 多步流转？} -->|否| ft["微调<br/>（固定风格/私有协议）"]`
  *分析：* 如果一个任务既不是简单分类（q1否）、也不需要文档检索（q2否）、也不需要多步Agent（q3否），它并不必然需要微调（例如复杂的 Prompt 链、固定工作流、摘要提取等）。导向“微调”会产生严重的选型误导。
- **修改建议：**
  在 q3 的“否”分支下增加二级判断或修正导向：
  ```mermaid
  q3{需要自主决策 + 调工具 + 多步流转？} -->|是| ag["智能体 Agent<br/>（第 11/12 章）"]
  q3 -->|否| q4{需要内化特定领域风格/格式/私有协议？}
  q4 -->|是| ft["微调<br/>（第 13 章进阶）"]
  q4 -->|否| wf["高级提示词工程 / 固定工作流<br/>（第 7/11 章）"]
  ```
